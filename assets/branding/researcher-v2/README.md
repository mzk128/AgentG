# AgentG Logo Exploration — 01-Researcher v2

## Brand interpretation

This collection uses the head silhouette of DeskPet `01-researcher-v2` as its visual reference: a rounded face, large oval eyes, a side-parted wavy bob, and outward hair tips. It preserves the reliable researcher personality while translating AgentG's architecture into a compact identity system.

- The **side part** is the main orchestration route.
- The **layered fringe** represents dependency-aware task flow.
- The **outward hair tips** represent Fan-out to specialist Workers.
- The **rounded face boundary** represents an isolated Worker context.
- Return arcs and terminal nodes represent Fan-in and Reviewer-directed revision.

All production SVGs use `viewBox="0 0 100 100"`, a transparent background, and `currentColor`.

## Concepts and suitable scenarios

| File | Direction | Best suited to | Why it fits |
|---|---|---|---|
| `researcher-v2-logo.svg` | Researcher Core | Main product logo, Web sidebar, app icon, social avatar | The clearest character connection and strongest recognition at 16–64 px. |
| `variant-02-worker-matrix.svg` | Worker Matrix | Architecture diagrams, feature badges, loading states, brand patterns | Discrete modules make specialist Workers and scalable teams immediately visible. |
| `variant-03-routing-waves.svg` | Routing Waves | Landing-page hero, motion identity, streaming/progress UI | Parallel hair-like curves communicate task flow, concurrency, and convergence. |
| `variant-04-fanin-face.svg` | Fan-in Face | Multi-Agent feature page, orchestration dashboard, presentation cover | One controller routes to four Workers inside a stable boundary, directly explaining the system. |
| `variant-05-agentg-monogram.svg` | AgentG Monogram | GitHub avatar, favicon, CLI/docs icon, SDK package mark | The `G` remains legible when character details must be reduced. |
| `variant-06-review-circuit.svg` | Review Circuit | Reviewer/observability module, audit reports, failure and revision states | The return arrow and graph nodes emphasize directed rework and closed-loop quality control. |

## Recommendation

`researcher-v2-logo.svg` was selected as AgentG's primary product logo and is integrated into the Web sidebar. It has a warmer and more grounded personality than the Pei-based proposal. `variant-05-agentg-monogram.svg` remains the strongest technical alternative for repository, favicon, and developer-tool surfaces.

Open `showcase.html` for dark/light comparison, use-case notes, and SVG downloads. The root `assets/branding/README.md` explains how this set compares with the Pei collection.
